Numera User Guide

Welcome to Numera, a high-precision calculator inspired by classic HP calculators. Whether you prefer traditional math notation or the powerful efficiency of a stack-based workflow, Numera adapts to your style.

Key Features at a Glance

  • Two Input Methods: Choose between traditional algebraic notation and Reverse Polish Notation (RPN).
  • High-Precision Core: Built on an advanced math engine that tracks full decimal precision behind the scenes, even when your display is rounded.
  • Smart Variables & History: Save your results locally, name them, and quickly recall or audit past calculations.
  • Live Conversions: On-the-fly conversion tools for global currencies and standard metric/imperial units.

Choosing Your Input Mode

You can change how you interact with Numera at any time by navigating to Settings → Input Mode.

Traditional Input Mode (Infix)

Use Numera like a traditional calculator. Type expressions exactly the way you would write them on paper (e.g., 5+5=). This mode should be familiar to anyone who has used a standard calculator.

RPN Input Mode (Stack-Based)

In Reverse Polish Notation, you enter numbers first and apply operators afterward. Instead of using an equals sign, values accumulate on a stack.

  • How the stack works: When you type a number and press Enter, it is pushed onto the stack.
  • Executing operations: Pressing an operator (like + or ×) instantly consumes the top values from the stack, performs the calculation, and pushes the new result back to the top.
  • Example: Press 2, Enter, 5, + — this calculates 2+5 and the stack now contains 7.
  • RPN input eliminates the need for parentheses in complex formulas and makes it easier to chain multiple complex operations together.
  • You can enter a temporary expression using traditional infix input by pressing (.

Calculator Modes

Numera offers four calculator modes, each providing a different set of buttons tailored to a specific type of work. You can switch modes at any time from Settings → Calculator Mode.

Standard

The everyday calculator. Covers the four basic arithmetic operations plus common helpers like square, square root, reciprocal, and percent. Memory slots let you park values for later. Also supports currency conversions.

Scientific

Expands Standard with a full function library for advanced math:

  • Trigonometry: Sin, Cos, Tan and their inverses and hyperbolic variants.
  • Powers & roots: x², x³, xʸ, and the corresponding roots.
  • Logarithms & exponentials: ln, log₁₀, log₂, eˣ, 10ˣ.
  • Combinatorics: Factorial, combinations, permutations, GCD, LCM.
  • Rounding: Floor, ceiling, truncate, round, integer part, fractional part.
  • Constants: π, e, speed of light, gravitational acceleration.

Use the Shift keys to access the alternate functions printed on each button.

Fraction

Keeps arithmetic exact by working with rational numbers symbolically, so 1÷3 stays as a fraction rather than 0.333…. Supports powers, roots, GCD/LCM, factorial. Also includes equation-solving tools: Use = to create an equation, Isol to isolate and solve for a variable and Flip to swap both sides of an equation.

Programmer

Designed for bit-level and integer work:

  • Base display: Switch to Programmer mode from Settings → Calculator Mode → Programmer — it opens at whichever base you used last. Change the base at any time using the Hex/Oct/Bin/Dec buttons on the Programmer keypad; the one in effect stays highlighted.
  • Hex input: Direct entry of digits A–F.
  • Bitwise operations: AND, OR, XOR, NOT (bitwise complement).
  • Bit shifting: Shift left and shift right.
  • Modulo: Integer remainder after division.

All four modes are available in both Traditional and RPN input styles.

Managing Data

Variables & Storage

Never lose a complex intermediate result. Numera allows you to name and save values as variables for later use:

  • Alpha: Use the Alpha (α) shift button to select variable names for storing or recalling values.
  • Store: Saves the current active value as a variable under a unique name.
  • Recall: Retrieves a saved variable by its name and places it back into your active calculation.
  • Variables Screen: You can tap the Var button to open a dedicated Variables screen.
  • Here, you can easily browse and recall any of the variables you have stored.

Currency Conversions

Numera includes a live currency browser that converts directly against your active value:

  1. Open the Currency browser from the menu.
  2. Select your Source currency to apply it to your value.
  3. Select your Target currency to instantly convert the value using live exchange rates.

Unit Conversions

The Units browser works the same way for physical measurements, and also lets you build compound units by combining dimensions:

  1. Open the Units browser from the menu.
  2. Select your Source unit.
  3. Select your Target unit to convert your value.

Automatic dimensional arithmetic: When both X and Y already carry units, the normal +, −, ×, ÷ keys combine their dimensions for you — e.g. a value in m/s times a value in s gives a result in m. No special button is needed for this.

Building a compound unit manually: Use ×Unit and ÷Unit, inside the Units browser, to attach a compound unit to X without changing its numeric value:

  1. Open the Units browser and apply a unit to your value (e.g., N for newtons).
  2. Press ×Unit or ÷Unit (shifted keys on Strip) to arm multiply or divide mode.
  3. Tap another unit to compose it into X's unit — e.g., tapping m after ×Unit turns 5 N into 5 N·m. The number stays 5; only the unit changes. (If X has no unit yet, ×Unit stamps the tapped unit directly, and ÷Unit stamps its reciprocal, e.g. 1/s.)
  4. Continue tapping units to keep composing; the engine tracks the resulting dimension.

Calculation History

Every calculation is automatically logged. Tap the History button to open a scrollable audit trail of your past work.

  • Re-use results: Tapping any entry in the log instantly copies that historical result and pushes it right back into your current calculation.
  • Housekeeping: Use the Clear History button inside the log to reset your workspace.

UI Tips & Hidden Shortcuts

The "?" Interactive Help Mode

Need to know what a specific button modifier does? Tap the "?" icon located in the top-left status bar to freeze the calculator and enter Help Mode. While active, you can tap any button on the layout to read a popup description of its exact function. To exit, simply tap the "?" icon again or tap the description popup.

Tap for Full Precision

By default, Numera rounds displayed values based on your preferences in Settings (e.g., two decimal places). If you ever need to inspect the exact underlying number, simply tap the value on the screen. This toggles the display between your clean, rounded preference and the engine's full raw precision.

Long-press for Copy, Paste and Stack Actions

Need to quickly copy a result or paste a value from another app, or reorder the RPN stack? Long-press on the result or a stack row to open a context menu:

  • Copy: Copy the selected value to your clipboard.
  • Paste: Paste a numeric value from your clipboard directly into the calculator to use for calculations.
  • Roll, RollD, and Pick (RPN stack rows only): Reorder the stack by rolling values up or down, or bringing a specific row to the top.

Drag to Resize the RPN Stack

When working in RPN mode, screen real estate matters. You can easily adjust your view by dragging the horizontal divider line between the stack display and the button layout up or down. Move it up to review deep stack history, or pull it down to keep your focus on the buttons.

Slide to a Shift Corner (Power User)

Trigger a shifted action in one motion instead of two: press down on a button and drag toward the corner holding the action you want — once the drag goes far enough, that corner arms: the button's label switches to show it, and the matching Shift key highlights to confirm. Release to commit it, or drag back toward the center to cancel. This also works for a button's Alpha letter, treated the same as any other corner.
